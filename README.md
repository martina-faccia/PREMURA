# Premura — app completa (prototipo PWA)

Questa versione funziona come app web/PWA e può essere pubblicata su GitHub Pages.

Funzioni:
- Home "Controllo"
- Profili bambino / anziano / animale / personale
- Promemoria rapidi in 3 passaggi
- Calendario
- Ricerca globale
- Documenti per profilo con ricerca, apertura e cancellazione
- Salvataggio locale nel browser
- Notifiche browser quando supportate
- Backup JSON import/export
- Service worker/offline cache

## Limiti prima della pubblicazione commerciale
Per una vera app pubblica servono autenticazione, database/cloud storage sicuro, GDPR/privacy,
push notification server-side affidabili anche ad app completamente chiusa.
